Elevvo Python Programming & AI
A collection of Python projects developed as part of the Elevvo training program.
Projects
Task 01 — CLI Expense Tracker
A command-line application for recording and managing expenses with JSON data persistence.
Technologies: Python, JSON
Task 03 — Automated File Organizer
A Python utility that organizes files into folders based on their file extensions.
Technologies: Python, pathlib, file handling
Task 08 — AI Code Reviewer
A command-line tool that uses a local DeepSeek model through Ollama to review Python code and generate structured JSON reports.
Technologies: Python, Ollama, DeepSeek R1 1.5B, JSON
Requirements
Requirements vary by project. Check each task's README for setup and usage instructions.
