
# Automated File Organizer

## Overview
A simple Python command-line application that automatically organizes files into folders based on their file extensions.

## Features
- Organizes files by extension.
- Creates folders automatically.
- Supports files without extensions by placing them in an Others folder.
- Prevents overwriting files with duplicate names.
- Validates the input folder path.

## Requirements
- Python 3.14 or compatible Python 3 version.

## How to Run
Run the following command from the Elevvo project folder:

```bash
python .\Task-03-File-Organizer\main.py
```

Enter the path of the folder you want to organize when prompted.

## Example
Files such as `notes.txt`, `photo.jpg`, and `report.pdf` are moved into the `TXT`, `JPG`, and `PDF` folders.
